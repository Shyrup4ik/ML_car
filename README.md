# AVTO — оценка автомобиля по фотографии

Русскоязычное локальное веб-приложение без регистрации. Frontend на HTML/CSS/JavaScript и backend на FastAPI работают с ML-частью из корневых `train.py` и `predict.py`.

## Установка и запуск

Нужен Python 3.12. Из папки проекта:

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-web.txt
.venv/bin/python run.py
```

На Windows вместо `.venv/bin/python` используй `.venv\Scripts\python.exe`.

Открой **http://127.0.0.1:7860/** и дождись готовности моделей. На macOS после установки можно запускать `start.command` двойным нажатием. Для остановки нажми Ctrl+C в терминале.

Другой порт: `AVTO_PORT=7861 .venv/bin/python run.py`.

## Файлы моделей

Положи результаты обучения в корень проекта рядом с `run.py`:

- `car_model.pt`: поддерживается прежний формат одной ConvNeXt-Tiny (`weights`) и текущий ансамбль (`members`). Сети кешируются при запуске; вероятности усредняются так же, как в текущем `predict.py`.
- `price_model.joblib`: нужен **текущий формат CatBoost со справочником `specs`**. Старый файл цены от HistGradientBoosting несовместим с текущей ML-частью. Его нужно переобучить командой `python train.py --price-only`, предварительно подготовив данные.

Веса и датасет не включены в Git. Порядок подготовки данных и обучения сохранён в [README.txt](README.txt) и [data/PUT_DATASET_HERE.txt](data/PUT_DATASET_HERE.txt).

Модель удаления фона U2Net скачивается библиотекой rembg при первом запуске. Для работы без сети заранее положи `u2net.onnx` в `models/rembg/`.

При ошибке загрузки backend продолжает отвечать на `/api/health`; подробная причина выводится в журнал терминала. Обученные файлы PyTorch/joblib следует брать из доверенного источника.

## Возможности сайта

- Загрузка JPG, PNG или WebP, перетаскивание, вставка скопированной картинки через ⌘V / Ctrl+V и кнопку «Вставить фото».
- Проверка года, пробега, размера и содержимого фотографии.
- Удаление фона, распознавание модели, цвета и кузова, три наиболее вероятных названия.
- Ручное исправление характеристик перед расчётом.
- Стоимость в GBP и RUB, диапазон P10–P90, курс ЦБ и дата курса.
- Графики стоимости по годам, сценарий будущей стоимости, влияние пробега и цвета, исторические сравнения.
- Адаптивный интерфейс на русском языке и плавные переходы.

Веб-форма пока не запрашивает объём двигателя, коробку и топливо: текущая модель цены подставляет типичные значения выбранного семейства. На странице результата показано предупреждение об этом. Для явного ввода этих характеристик доступен текущий CLI `predict.py`; его использование описано в `README.txt`.

После `--price-only` сквозная ошибка цены по фото может отсутствовать. Отсутствующие метрики показаны как «не измерялась», а не как нулевая ошибка. Метрики из файла цены относятся к сохранённой проверке DVM-CAR и не являются новой проверкой качества на пользовательских фото.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | Готовность моделей |
| GET | `/api/metadata` | Доступные модели и характеристики, метрики, курс |
| POST | `/api/recognize` | Фото в multipart-поле `photo` |
| POST | `/api/estimate` | JSON: `session_id`, `model`, `year`, `mileage_km`, `color`, `body` |
| DELETE | `/api/sessions/{session_id}` | Удаление сессии |

Описание API со встроенными локальными ресурсами: **http://127.0.0.1:7860/docs**.

## Устройство и ограничения

`app/` содержит API и кеширующий адаптер к текущей ML-части. `frontend/` содержит интерфейс, изображения и локальные ресурсы Swagger. `tests/` содержит проверки API и совместимости форматов распознавания. `requirements-web.txt` подключает исходные `requirements.txt` и добавляет веб-зависимости. Корневые скрипты обучения и их зависимости сохранены.

Приложение запускается на `127.0.0.1` и не публикует сервер в интернет. Фото не записываются в папку проекта. Сервер хранит в памяти характеристики распознавания до 30 минут, не более 32 сессий; подготовленная картинка отображается в браузере.

Оценка относится к британскому рынку, с переводом GBP в RUB. Перевод валюты не делает её оценкой российского рынка. Данные и индекс цен используются из ML-части проекта; сценарий будущей стоимости не является прогнозом рынка или курса. Проверяй распознанные характеристики: качество на обычных фото может отличаться от сохранённых метрик DVM-CAR.

## Проверки

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

API проверяется без обученных весов. Отдельные проверки подтверждают загрузку схем одиночной сети и ансамбля и усреднение вероятностей. Полное качество текущих обученных моделей нужно измерять на независимых фотографиях после предоставления новых весов.
